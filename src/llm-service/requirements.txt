# --- 方案 A：llama-cpp-python（推荐） ---

# 默认从源码编译，需要本地 C/C++ 工具链（Windows: Visual Studio 或 MinGW）。
# 编译时间约 5~20 分钟，取决于机器性能。
#
# 若想直接使用预编译 wheel（不编译，推荐）：
#   CPU：pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
#   CUDA 12.4：pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
#   Metal (macOS)：pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/metal
#   Vulkan：pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/vulkan
#
# 详细说明见：llama_cpp_python_guide.md
llama-cpp-python>=0.3.0


# --- 方案 B：transformers + torch（备选） ---

# 仅当不使用 llama-cpp-python 时启用。

#       因此推荐使用方案 A。以下两行仅供实验用途。

# -----------------------------------------------------------------------------
# 7. 说明：不在 pip 中的依赖
# -----------------------------------------------------------------------------
#
# 下列组件由系统提供，不通过 pip 安装：
#
#   LingoFuse64.dll / liblingofuse.so / liblingofuse.dylib
#       核心动态库。放在系统 PATH，或与 .py / .exe 同目录。
#       下载：https://github.com/PassByYou888/LingoFuse/releases
#
#   z_ipc_64.dll / libz_ipc.so
#       IPC 引擎依赖，与 LingoFuse 动态库同目录。
#
#   GGUF 模型文件
#       例如 qwen2.5-7b-instruct-q4_k_m.gguf（约 4.7 GB）。
#       放在 llm_service_*.exe 同目录，或通过 --model-path 指定。
#       下载：见 Qwen2.5-7B-Instruct-Q4_K_M.md
#
#   OpenAI 兼容后端（可选）
#       若使用 llm_proxy.py，需要先启动一个后端，例如：
#         - LM Studio Local Server （https://lmstudio.ai）
#         - Ollama                （https://ollama.com）
#         - vLLM / SGLang / TGI   （自建）
#       或使用云 API：DeepSeek / SiliconFlow / OpenRouter / Groq 等。
